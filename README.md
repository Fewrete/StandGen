# StandGen
Це поки що прототип моду для Minecraft, який пародірує JoJo. Но воно прямо нічого не бере, і стенд буде створений завдяки ваших дій. Цей мод створений ШІ, тому можуть баги та багато іншого. У моді є: різні типи стендів (Гуманойд, зброя, обладунки і рій), який тип стенду з повишеним шансом випаде, завісе від ваших дій.

# StandGen (Fabric 1.20.1)

Стенди генеруються з дій гравця, мають форму (Гуманоїд / Броня / Зброя / Рій) і ростуть разом з прогресом у грі.

## Встановлення мода (для гравців та збірок)
- Fabric Loader для Minecraft 1.20.1
- Fabric API для 1.20.1 (єдина залежність мода)
- standgen-x.y.z.jar у папку mods

## Гра
- Крафт: Стріла + Алмаз + Золотий злиток (безформний). ПКМ - пробудження стенда.
- Тест: `/stand awaken`, `/stand info`, `/stand reset` (потрібні права op).
- Клавіші: R виклик/прибрати, X здібність 1, C здібність 2.

## Як це працює
- Душа = ванільна статистика (копання, вбивства, будівництво, дистанція, лук, смерті/шкода).
- Стадія = кількість виконаних віх (Progression.java). Росте стадія -> характеристики, вигляд, здібності.
- Форма (StandForm): Гуманоїд +точність, Броня +стійкість, Зброя +сила, Рій +швидкість/дальність.
  Моделі з кубів у client/StandModels.java.
- Інші моди: `StatCollector.register(...)` додає бали типам, `Progression.addMilestone(...)` додає віхи.
